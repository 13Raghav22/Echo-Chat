# 💬 EchoChat

EchoChat is a real-time multi-client chat application built using **Python, Socket Programming, and Tkinter GUI**.  
It allows users to communicate instantly and share images and files across connected clients.

---

## 🚀 Features

- Real-time messaging
- Multi-client chat system
- Username identification
- Image sharing
- File sharing
- Modern GUI interface
- Scrollable chat area
- Enter key message sending

---

## 🛠 Technologies Used

- Python
- Socket Programming
- Tkinter GUI
- Multithreading

## ▶️ How to Run

### 1️⃣ Start the server


python server.py


### 2️⃣ Run the client

Open another terminal:


python client.py


### 3️⃣ Run multiple clients

Open additional terminals and run:


python client.py


Now multiple users can chat in real time.
